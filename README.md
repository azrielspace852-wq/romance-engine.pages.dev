# ROMANCE ENGINE

**Romance Engine:** is a cinematic declaration of love site

## Folder Structure

**public:*** (pages)
```text
   romance-engine-pages/
   └── public/
       ├── index.html
       ├── create.html
       ├── view.html
       └── assets/
           ├── audio/
           │   └── default-bgm.mp3
           ├── css/
           │   └── style.css
           └── js/
               ├── 3d-hearts.js
               ├── audio-player.js
               └── interactive.js
```

**src:** (workers)
```text
   romance-engine-worker/
   └── src/
       └── index.js
```

**full structure:** (all files and folders)
```text
   romance-engine/
   ├── public/
   │   ├── index.html
   │   ├── create.html
   │   ├── view.html
   │   └── assets/
```
